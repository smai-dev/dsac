# Applied Data Science & Machine Learning Portfolio

This repository brings together a set of hands-on data science and machine learning projects covering **classical ML, NLP, causal text analysis, web mining, big-data processing, and end-to-end analytical workflows**.

The focus is not only on applying algorithms, but on understanding the full workflow: **data exploration, preprocessing, feature engineering, model selection, evaluation, interpretation, and scalability**.

## Projects

| Area | Main Topics |
|---|---|
| **Clustering** | K-Means, DBSCAN, scaling, Silhouette Score, Davies–Bouldin Index |
| **Classification** | Logistic Regression, Decision Trees, XGBoost, KNN, SVM, cross-validation |
| **Regression** | Linear Regression, Ridge, ElasticNet, model evaluation |
| **Association Mining** | Apriori, frequent itemsets, support, confidence, lift, leverage |
| **CRISP-DM Project** | End-to-end predictive analytics, feature engineering, imbalance handling, Random Forest, XGBoost |
| **Web Content Mining** | Selenium scraping, NLP preprocessing, TF-IDF, SVD, clustering, LDA topic modelling |
| **Causal NLP Research** | Topic modelling, semantic causal-claim analysis, causal-frame networks, synthetic-data validation, LLM-assisted analysis |
| **Apache Spark** | PySpark DataFrames, partitioning, Window functions, Parquet, MLlib pipelines, predictive maintenance |

## Key Learning Outcomes

The work demonstrates practical experience with:

- building reproducible data-processing and machine-learning pipelines;
- selecting algorithms based on data characteristics rather than applying models blindly;
- preventing data leakage and evaluating models using appropriate metrics;
- handling missing data, outliers, class imbalance, categorical variables, and feature scaling;
- tuning models with cross-validation, Grid Search, and Randomized Search;
- interpreting model outputs and understanding the limits of predictive conclusions;
- mining and modelling unstructured text using NLP and unsupervised learning;
- reasoning about scalability using Apache Spark and distributed data-processing concepts.
